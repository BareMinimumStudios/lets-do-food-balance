# Changelog

## 1.0.0

- Added configurable maximum aging per Vinery drink, including a no-aging option.

- Vinery drink stack size is limited to 4.

- Initial release.
- Balances selected food and drink effects from Let's Do: Vinery, Brewery, and Farm & Charm.
- Supports individual effect toggles for each supported Vinery and Brewery drink.
- Supports handheld and placed foods.
- Preserves Vinery aging and Brewery quality behavior.
- Includes Mod Menu configuration and tooltip filtering for disabled effects.
- Includes optional Incapacitated compatibility for golden apples, golden carrots, and enchanted golden apples.
